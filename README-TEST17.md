# Glimbraid test17 – klar til siste APK-kontroll før AAB

Brettrekorder og kategorirekorder (beste tider og færreste trekk summert over 12 brett). Alle seks lokale spillere vises; ufullstendige kategorier vises med antall rekorder uten rangering. Alle 15 språk er oppdatert. Lagrede data og kjøpsmodell fra test16 beholdes.

Android-deling er justert til separat oppgave. Snapchat/MMS og tilbakeknapp må bekreftes på fysisk telefon. iOS-delingsflyten er ikke endret.

Regresjonstester bestått, inkludert alle 96 brett og 66 240 relevante hintforslag. 390 nettleservisninger uten registrerte feil. APK er bygget med R8, uten debug-flagg, samme testsertifikat og versjonskode 17. DEX: 1 233 380 ukomprimerte bytes. Alle webressurser og native broer er kontrollert.

Dette er test-APK. Produksjons-AAB og butikkjøpstesting gjenstår. iOS-kilde med samme rekordlogikk er oppdatert til byggenummer 17; IPA er ikke bygget. Se RECORDS-TEST17.md og PAYMENT-SETUP.md.
