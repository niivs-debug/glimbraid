# Glimbraid 1.0.3 – versjonskode 23

Åtte egne brikkeoverflater følger kapitlene: nattblått, skoggrønt, isblått, rav, nordlysgrønt, indigo, gull og lilla. Fargene brukes også i løsningsforhåndsvisning og er knyttet til brettets kapittel. Lysstrømmer, funksjonsmarkeringer, 96 brett, hintbank, premier, språk og kjøpslogikk er beholdt.

Android: API 36, min Android 7, R8 og ressurskrymping beholdt. Apple-prosjektets delte webressurser er synkronisert, men IPA er ikke bygget eller publisert i denne oppdateringen.

Kildegrunnlag: versjon 1.0.2 (22). Det forrige ZIP-arkivet var avbrutt på slutten; alle gjenopprettede kildefiler ble kontrollert med ZIP-kontrollsum, og manglende felles verktøy/testfiler ble hentet fra det komplette arkivet 1.0.1 (21).

Validering: eksisterende regresjonssuite bestått; ekstra kontroll av riktig kapittelfarge og brikkeantall på alle 96 brett. Brettdata, hint, kjøp, språk og avatarer sammenlignet byte for byte med forrige uendrede spillgrunnlag. Visuell nettleserkontroll av alle åtte kapitler på 360 × 800: riktig farge, alle brikker innenfor skjermbredden og ingen JavaScript-feil. Fysisk prøvespilling av den nye Android-utgaven anbefales før produksjon.

Rekkefølge videre: Google Play-oppdatering, deretter Apple, deretter PC-demo og Steam-vurdering. Se UTVIKLINGSPLAN.md.

## Forslag til versjonsnotat
Hvert kapittel har fått sin egen fargetone på brikkene. Opplev tydeligere variasjon gjennom alle 96 brett, med samme spilleregler og fremdrift som før.
